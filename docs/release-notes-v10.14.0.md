**Ping 结果多了两列：厂商 + 系统**

Ping 原来只回答「通不通、多快、丢多少」。现在结果表会读本机 ARP 邻居表（同网段取不到的再用 SendARP 补一次），用 MAC 前缀查 **IEEE 全量厂商库**（五张注册表 59,368 条，随包 0.64 MB，按 9 → 7 → 6 位最长前缀匹配）；再用回包剩余 TTL 粗推系统家族（Windows / Linux-Unix / 网络设备）。

**不发任何探测包**

只读本机 ARP 表与已收到的 ICMP 回包，不向目标额外发包，不会在企业网里留下扫描特征，因此默认开启。

识别在 Ping 完成后的独立阶段执行，不进 Ping 热路径，失败只影响这两列。

**细节**

- 厂商库离线可用；Ping 页右侧「厂商库」按钮可联网更新到最新（按文件显示进度，可中止，失败不影响原库）
- 厂商名过长时列内显示压缩短名，悬停看完整名与 MAC
- 未收录的前缀显示 MAC 而不写「未知」，便于自行核对
- 系统列悬停显示「TTL=NN，推断约 N 跳；仅供参考」
- 支持外挂 `oui.json` 覆盖厂商结果
- 跨网段取不到 MAC 属协议限制，该列留 `-`

**验证**：设备识别 88 条断言、中英界面各 17 项（含导出与厂商库按钮联动）、安装卸载闭环 19/19 全过。
