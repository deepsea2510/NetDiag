NetDiag 网络诊断工具 v10.14.0 —— 便携版使用说明
================================================

【怎么用】
1. 把整个 NetDiag 文件夹拷到目标电脑（U 盘、共享盘都行），路径不要紧，但不要只拷 NetDiag.exe，
   同目录的 _internal 文件夹是运行库，必须一起拷。
2. 双击 NetDiag.exe 直接运行，不需要安装、不需要管理员权限、不需要 Python 环境。

【运行环境】
- Windows 10 / 11 64 位（Windows 7 未验证）
- 首次运行若被 SmartScreen 拦下：更多信息 → 仍要运行
- 依赖系统自带的 VC++ 运行库（Win10 1809 以上默认已有）
- WMI 查询依赖系统 PowerShell（Win10/11 自带）

【目录里有什么】
NetDiag.exe          主程序
_internal\           运行库（Qt、Python 及依赖，勿删勿动）
dicts\               外挂字典示例（sample-pairs.txt / sample-passwords.txt）
fingerprints\        内置服务指纹规则 default.json（可复制后改，在界面里勾选用）
wmi\                 WMI 预设示例 presets.json（可复制后改，在界面里外挂）
syslog\              Syslog 归类/告警规则 rules.json（可复制后改，在界面里外挂）
README.md            完整功能说明与参数

【能做什么】
- 本机网络信息、网关与网段探测
- 批量 Ping / 端口扫描（TCP、UDP、常见端口预设、自定义「端口:协议」）
  v10.14 新增：Ping 结果表格多了「厂商」「系统」两列。勾选「识别厂商 / 系统」后，
  Ping 结束会读取本机 ARP 邻居表（同网段取不到的再用 SendARP 补一次），用网卡 MAC
  前缀查 IEEE 全量注册表（59,368 条，按 9 → 7 → 6 位十六进制最长前缀匹配），
  并按回包剩余 TTL 粗推系统家族（Windows / Linux-Unix / 网络设备），
  鼠标悬停可看完整厂商名、MAC 与推断跳数。只读本机 ARP 表、不向目标发探测包；
  跨网段取不到 MAC 时该列留「-」，厂商库未收录时显示 MAC 便于自行核对。
  「厂商」列识别完会按当前最长的厂商名自适应加宽（窗口拉宽给得更多）；
  仍放不下的长名字，双击「厂商」表头可按内容铺满，或直接悬停看完整名。
  右侧「厂商库」按钮显示当前条数与来源，点击可联网更新到最新（写入
  %APPDATA%\NetDiag\oui\，立即生效；慢速网络按文件显示进度，再点一次可中止）
- 弱口令与未授权访问探测（17 类协议，默认关闭，需手动勾选）
- 服务指纹库：内置 120 条规则，可外挂 JSON 扩展，横幅测试台可验证匹配
- 路由跟踪 / DNS 查询 / SNMP 遍历
- WMI 只读查询：本机与远程（IP + 账号密码），15 条内置预设，支持自定义命名空间与 WQL；
  远程默认走 DCOM（需目标放行 135 及 RPC 动态端口），查不到会自动回退 WinRM
- Syslog 服务器：本机起 UDP/TCP 监听（默认 1514），自动识别 RFC3164 / RFC5424 / 裸文本，
  36 条内置归类与告警规则，日志与预警均可导出
- Syslog 存储设置：可选本地 SQLite（自定义路径）、按日志源分文件并按体积/时间归档
  （gzip、保留份数），或写入 MySQL / PostgreSQL / SQL Server / Oracle / ODBC 等数据库；
  配置在「存储设置…」里改，口令在本机加密保存；连不上外部库时自动回退本地 SQLite
  v10.11 新增「生成初始化 SQL…」：按数据库类型生成建库 / 授权 / 建表脚本交 DBA 执行，
  不会自动新建数据库实例，也不会把当前口令写进脚本；测试连接会分类提示驱动、网络、
  认证、权限、库不存在、表结构不匹配等原因
  v10.12 新增：内置 SQLite 默认达到 500 MB 自动换新库（阈值在「存储设置…」里改，
  0 = 不分片），旧分片会保留；点 Syslog 页「历史查询…」可同时查当前库、全部旧分片
  以及文件归档的活动 JSONL 与 gzip 归档，支持关键字/来源/级别/分类/最近时长过滤并导出
  监听地址下拉可选「仅本机 / 所有网卡 / 各块网卡 IP」（点框右侧小三角展开，也可直接手输），
  进入页签自动识别，可点「⟳ 网卡」重新识别
- 界面配色：右上角「颜色模式」可选 浅色 / 深色 / 跟随系统 / 自定义颜色
  （深色适合夜间值守；自定义可换强调色与底色，会记住上次选择）
  所有窗口的标题栏（主窗口、各类对话框、提示框）都会跟着所选配色一起变
- Ping 在线结果可直接送入扫描 / SNMP / WMI 目标：右键在线行选目标，
  或在 SNMP / WMI 目标框右侧点「Ping 结果 ▾」从已探测主机中挑（自动去重、只列在线）
- 结果可排序；各面板均可导出 CSV / JSON 报告（元数据含版本 10.14.0）
  v10.13 新增：界面支持中文 / English 多语言，首次启动按操作系统语言自动适配
  （中文系统 → 简体中文，其余 → English）；菜单栏「语言/Language」可随时切换
  （自动/简体中文/English），选择会记住。窗口、标签页、按钮、菜单、表格表头、
  对话框、结果预览状态行、说明文字与下拉选项均已翻译；切换语言后动态状态文本
  会即时刷新，仅语言菜单项保留母语名称
  v10.13.1 修复：分组标题（批量 Ping 诊断 / 扫描概览 / 路由跟踪结果…）、表格状态列
  （在线 / 离线 / 响应）、统计行、右键菜单与按钮运行态此前漏翻，现已全部随语言切换
  v10.13.2 修复：Ping 页「识别本机网卡」下拉首项在切英文后点按钮会退回中文；
  「探测设置…」等按钮英文文字被裁；表格英文表头（如 Protocol）被裁
  v10.13.3 修复：扫描结果「弱口令」列的探测结论（HTTP 200，未发现登录表单 /
  已试 31 组 / 未授权（API 7.10）这类带变量的句子）在英文界面仍显示中文；
  统计行「未授权」、Syslog 分类列、Syslog 监听地址下拉的括号也随语言切换了
  v10.13.4 新增：安装向导与卸载确认框也会跟随系统语言显示中文或英文
  （英文系统装机会看到英文向导；可用 NETDIAG_LANG=zh_CN / en_US 强制指定）
  （英文介绍见 README_EN.md）

【注意】
- 只做本地网络探测，数据不上传
- 弱口令探测仅用于你已获得授权的资产；部分设备有账户锁定策略
- WMI 远程查询需要目标机的管理员凭据与 DCOM/WMI 权限
- Syslog 默认只监听 127.0.0.1；要给其他设备发日志，从下拉选本机网卡 IP（只在该网卡收包）
  或选 0.0.0.0（所有网卡），并放行防火墙入站端口
- 便携版不会写注册表，删除文件夹即完成卸载；桌面快捷方式需自行创建

【想要安装版】
用 NetDiagSetup-10.12.exe（安装包单独分发）：
- 默认装到 C:\Program Files\NetDiag，会弹一次系统授权（UAC）窗口，点「是」即可；
- 不想提权，就把安装目录改成 %LOCALAPPDATA%\Programs\NetDiag，全程不需要管理员权限；
- 装完自动创建桌面/开始菜单快捷方式，卸载在「设置 → 应用」里。
